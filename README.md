# SparkGuard: Big Data Pipeline for High-Frequency Transactions

Distributed fraud detection pipeline using Apache Spark MLlib and Scala on credit card transaction data.

## Team Members & Roles
- **Bhavani Patangay** (PM & Data Engineering): Preprocessing, scaling, splitting
- **Samuel Yeneneh** (Baseline Modeler): Random Forest
- **Caleb Dow** (Advanced ML Engineer): Support Vector Machine (SVM), Voting Ensemble
- **Pritom Dutta** (DL Lead): Neural Networks
- **Sucharitha Shivva** (Evaluation & Integration): XGBoost, performance metrics & evaluation

## Technology Stack & Environment
- **Scala**: 2.12.x (Scala SDK 4.7.0)
- **Spark**: 3.0.0-preview2 (Hadoop 2.7)
- **Java**: JDK 8u202
- **Dataset**: Kaggle `creditcard.csv` (Place in `/data/` directory)
